# 🧭 پنل بررسی اوتباند Connecso

**فارسی** · [English](README.md)

پنلی خودمیزبان برای بررسی مسیرهای پروکسی از لینک اشتراک یا کانفیگ‌های واردشده، مرور بررسی‌های قبلی و خروجی‌گرفتن اوتباندهای سالم در قالب JSON.

## ✨ امکانات
- دریافت لینک HTTPS اشتراک یا واردکردن متن ساده/Base64 کانفیگ‌ها.
- انتخاب پروتکل برای بررسی: VLESS، VMess، Trojan، Shadowsocks و Hysteria2. اوتباندهای WireGuard و MASQUE در قالب JSON استاندارد Xray پذیرفته می‌شوند. AmneziaWG اوتباند بومی Xray نیست و در این برنامه با آن پروتکل آزمایش نمی‌شود.
- اسکن اولیه فقط RTT مسیر HTTPS و زمان اتصال مستقیم TCP سرور بررسی به مقصد را اندازه می‌گیرد. برای مقصدهای UDP زمان اتصال مستقیم به‌جای حدس‌زدن نامشخص نمایش داده می‌شود.
- با بازکردن هر کانکشن، دسترسی ۶۱ مقصد شبکه‌های اجتماعی، سرویس‌های عمومی و هوش مصنوعی، بازی‌ها و دانلود/پشتیبانی بررسی می‌شود. این کار از یک فرایند تعاملی جداگانهٔ Xray استفاده می‌کند.
- تنظیم خودکار تعداد workerها بر اساس رم آزاد؛ هر worker تا ۱۰ مسیر را هم‌زمان بررسی می‌کند و بخش جداگانه‌ای از فهرست می‌گیرد.
- فیلتر کشور و پروتکل، جست‌وجو، مرتب‌سازی، یافتن موارد تکراری و کپی/دریافت JSON گروه‌بندی‌شده بر اساس کشور.
- بازکردن یا اجرای دوبارهٔ بررسی‌های ذخیره‌شده. اجرای دوباره لینک اشتراک را از ابتدا دریافت می‌کند و اجازه می‌دهد پروتکل‌هایی مثل Shadowsocks را انتخاب یا لینک را عوض کنید. برای سابقه‌ها نام و برچسب بگذارید یا آن‌ها را نشان‌گذاری کنید.
- با کلیک روی سرویس، پایش زندهٔ همان مقصد هر ۵ ثانیه شروع می‌شود و با همان دکمه متوقف می‌شود. بررسی دوبارهٔ مسیر و تست چنداتصالی دانلود پنج‌ثانیه‌ای هم در worker تعاملی انجام می‌شوند.
- رابط فارسی/انگلیسی، پوستهٔ روشن/تیره و ورود مدیر با رمز عبور.

این برنامه فقط کانفیگ‌ها را بررسی و خروجی می‌سازد؛ پنل دیگر، کاربران، قوانین مسیریابی یا سرویس Xray موجود را تغییر نمی‌دهد. فرایندهای موقت Xray فقط هنگام بررسی اجرا می‌شوند.

اطلاعات کشور از پایگاه ماهانهٔ [DB-IP Lite](https://db-ip.com) گرفته و در پوشهٔ داده‌های پنل نگه‌داری می‌شود. این کار Xray اضافه‌ای اجرا نمی‌کند. لینک منبع داده نیز در پایین صفحه درج شده است.

## 🧪 روش بررسی
اسکن کلی فقط RTT مسیر را بررسی می‌کند. workerهای موقت Xray بخش‌های جدا و بدون هم‌پوشانی از اشتراک می‌گیرند و هرکدام تا ۱۰ مسیر را هم‌زمان بررسی می‌کنند. برنامه برای سیستم و worker تعاملی جداگانه ۶۴۰ مگابایت حافظه کنار می‌گذارد و تعداد workerهای اسکن کلی را خودکار تا سقف سه عدد تنظیم می‌کند. مسیرهای تکمیل‌شده ذخیره می‌شوند تا ادامهٔ یک اسکن نیمه‌تمام فقط موارد باقی‌مانده را بررسی کند. اجرای دوبارهٔ کامل، لینک اشتراک را دوباره می‌خواند و از ابتدای فهرست آغاز می‌شود. RTT نمایش‌داده‌شده زمان پاسخ HTTPS از مسیر همان کانفیگ است، نه پینگ ICMP. زمان مقصد مستقیم، زمان اتصال TCP از سرور بررسی به endpoint کانفیگ است و پینگ کاربر نیست. بررسی سرویس‌ها، پایش زندهٔ ۵ثانیه‌ای، بررسی دوبارهٔ مسیر و تست دانلود از Xray موقت جداگانه استفاده می‌کنند و حین اسکن کلی هم قابل اجرا هستند. نشانگر سرویس فقط دسترسی HTTPS به وب‌سایت را می‌سنجد، نه پینگ سرور بازی یا ورود به حساب. تست دانلود تنها با درخواست کاربر اجرا می‌شود.

## 🧰 نیازمندی‌ها
- سرور Ubuntu یا Debian با دسترسی root.
- رکورد DNS نوع A که هنگام صدور گواهی مستقیماً به IPv4 عمومی سرور resolve شود.
- دسترسی موقت به پورت ۸۰ برای چالش صدور گواهی HTTP-01.
- بازبودن پورت HTTPS انتخاب‌شده در فایروال سرور و ارائه‌دهنده.
- Xray؛ نصب‌کننده در صورت وجود از فایل محلی استفاده می‌کند، وگرنه نسخهٔ جداگانه‌ای نصب می‌کند و سرویس Xray موجود را مدیریت نمی‌کند.

## 🚀 نصب یا ادامهٔ نصب
با کاربر root اجرا کن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SocalledTaha/connecso-vless-audit/main/quick-install.sh)
```

نصب‌کننده دامنهٔ پنل، پورت HTTPS، ایمیل اختیاری گواهی و رمز مدیر را می‌پرسد. اگر نصب نیمه‌کاره ماند، همان دستور را دوباره اجرا کن تا از مرحلهٔ ذخیره‌شده ادامه دهد.

## ⚙️ مدیریت پنل
پس از نصب، `ConnecsoTools` را با هر ترکیبی از حروف بزرگ و کوچک، یا `CTS`/`cts` را وارد کن تا منوی نگهداری باز شود. منو می‌تواند TLS را تمدید یا دوباره صادر کند، دامنه یا پورت HTTPS را تغییر دهد، پنل را عیب‌یابی و لاگ‌های اخیر را نمایش دهد، از GitHub به‌روزرسانی کند، سرویس را راه‌اندازی مجدد کند یا رمز مدیر را عوض کند.

داخل پنل هم دکمهٔ **به‌روزرسانی** نسخهٔ تازهٔ GitHub را در پس‌زمینه نصب می‌کند، سابقهٔ بررسی و رمز را نگه می‌دارد، فقط همین پنل را دوباره راه‌اندازی می‌کند و پس از آماده‌شدن صفحه را تازه می‌کند. هر بررسی تا ۲۵۰۰ کانفیگ را می‌پذیرد و نتیجه‌ها را مرحله‌ای ذخیره می‌کند؛ می‌توانی مرورگر را ببندی و بعداً از سابقه برگردی.

## 🔐 داده و امنیت
- لینک اشتراک باید HTTPS باشد و به IP عمومی resolve شود؛ مقصدهای محلی و خصوصی رد می‌شوند.
- بررسی‌های ذخیره‌شده، نام، علاقه‌مندی‌ها، برچسب‌ها و وضعیت نصب در `/var/lib/vless-audit/` می‌مانند. اگر بررسی با لینک اشتراک انجام شده باشد، رکورد نتیجه URL آن را هم نگه می‌دارد؛ دسترسی سرور و نسخه‌های پشتیبان را محافظت کن.
- سرویس با کاربر غیرمدیر و محدودیت‌های فایل‌سیستم systemd اجرا می‌شود.
- تست اختیاری دانلود پنج ثانیه طول می‌کشد و از چهار جریان هم‌زمان استفاده می‌کند.
- برای مسیرهای موفق، RTT درخواست HTTP از تونل و زمان اتصال TCP از سرور بررسی تا IP مقصد جداگانه نمایش داده می‌شود. زمان اتصال مستقیم ممکن است برای مقصدهای UDP یا میزبان‌هایی که TCP را مسدود کرده‌اند در دسترس نباشد.
- لاگ‌ها را systemd-journald نگه می‌دارد؛ منوی نگهداری ۴۰ رویداد اخیر را نشان می‌دهد.

## 🗑️ حذف پنل
مخزن نصب‌شده در مسیر `/opt/vless-audit/project-source` قرار دارد. دستور زیر را با مسیر کامل اجرا کن؛ لازم نیست ابتدا وارد پوشه شوی:

```bash
sudo bash /opt/vless-audit/project-source/uninstall.sh
```

این دستور فقط سرویس `vless-audit` را متوقف و غیرفعال می‌کند و فایل‌ها و تنظیمات همین برنامه، دستور نگهداری و hookهای تمدید گواهی مخصوصش را پاک می‌کند. به‌طور پیش‌فرض بررسی‌های ذخیره‌شده، وضعیت نصب و کاربر/گروه سرویس در `/var/lib/vless-audit/` باقی می‌مانند.

برای پاک‌کردن داده‌های ذخیره‌شده و کاربر/گروه سرویس هم این دستور را اجرا کن:

```bash
sudo bash /opt/vless-audit/project-source/uninstall.sh --purge-data
```

حذف‌کننده بسته‌های سیستمی یا Xray را حذف نمی‌کند و به پنل‌های دیگر، وب‌سرورها و گواهی‌های اصلی Let's Encrypt دست نمی‌زند. چون هنگام حذف، پوشهٔ مخزن هم پاک می‌شود، اگر بعداً خواستی داده‌ها را با گزینهٔ `--purge-data` جداگانه پاک کنی، ابتدا مخزن را دوباره دانلود یا clone کن.
